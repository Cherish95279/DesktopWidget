# Privacy Policy

Last updated: 2026-08-03

## Overview

DesktopWidget is a Windows desktop widget application that provides features including clock display, weather information, system monitoring, network monitoring, lunar calendar, solar terms, customizable themes, announcements, and automatic updates.

We respect user privacy and only collect limited anonymous technical and usage information to improve application quality, stability, and user experience.

DesktopWidget does not require users to create an account and does not collect personally identifiable information.

---

## Information We Collect

DesktopWidget may collect limited anonymous technical and usage information, including:

* Anonymous installation identifier (randomly generated UUID)
* Application version information
* Windows operating system version
* Application update status
* Weather service status
* Automatic startup setting status
* Selected user interface theme
* Application language setting
* Screen resolution information
* Widget configuration and layout settings
* Application runtime statistics

The anonymous installation identifier is randomly generated and does not contain personal information. It is used only to distinguish different installations for statistical purposes.

This information is used only for:

* Improving application stability
* Understanding feature usage
* Detecting compatibility issues
* Improving user experience
* Planning future improvements

---

## Weather Information

To provide weather services, DesktopWidget sends the weather location configured by the user.

This information may include:

* Selected city name
* Geographic coordinates (latitude and longitude) of the selected city

This location represents the user's chosen weather location and is not obtained from Windows location services.

DesktopWidget does not collect:

* Real-time GPS location
* Device location services data
* User movement information

---

## Country and Region Statistics

DesktopWidget may process network information to generate anonymous country or region statistics.

This process may use the user's IP address to determine an approximate country or region through an IP geolocation service.

The purpose is only to understand global usage distribution.

DesktopWidget:

* Does not store IP addresses
* Does not collect precise geographic locations
* Does not track individual users across locations

Only anonymous country or region statistics are retained.

---

## Information We Do Not Collect

DesktopWidget does not collect:

* Names or personal identification information
* Email addresses
* User files or documents
* Passwords
* Browsing history
* Hardware serial numbers
* Hardware fingerprints
* GPS location data
* Precise device location
* Personal account information

---

## Third-Party Services

DesktopWidget may use third-party services to provide certain functions, including:

* Weather information services
* Application update services
* IP geolocation services for anonymous country statistics

These services receive only the information necessary to provide the requested functionality.

DesktopWidget does not sell, rent, or share user information for advertising or marketing purposes.

---

## Data Storage and Security

Anonymous statistics may be transmitted through secure network connections and stored on DesktopWidget servers for statistical analysis.

The collected information is designed to be anonymous and does not include personally identifiable information.

Reasonable technical measures are used to protect collected data from unauthorized access.

---

## Updates

DesktopWidget may periodically check for new versions.

Update checks may transmit the current application version to determine whether a newer version is available.

No personal information is required for update checks.

---

## Data Retention

Anonymous usage statistics are retained only for application analysis and improvement purposes.

Users may stop data transmission by choosing not to use versions of DesktopWidget that include anonymous statistics features.
