# Privacy Policy

Last updated: 2026-07-25

## Overview

DesktopWidget is a Windows desktop widget application that provides features including clock display, weather information, system monitoring, network monitoring, lunar calendar, solar terms, customizable themes, announcements, and automatic updates.

We respect user privacy and only collect limited anonymous information to improve application quality and user experience.

## Information We Collect

DesktopWidget may collect limited anonymous usage and technical information, including:

- Daily active device count (anonymous statistics only)
- Windows version information (Windows 10 or Windows 11)
- Application update check status
- Weather update success or failure status
- Application configuration information, such as whether automatic startup is enabled
- User interface settings, such as selected theme

This information is used only for:
- Improving application stability
- Understanding feature usage
- Fixing compatibility issues
- Improving user experience

## Weather Information

To provide weather services, DesktopWidget sends the location configured by the user.

This location information may include:

- City name
- Geographic coordinates (latitude and longitude) of the selected city

This information represents the user's selected weather location and is not collected from the user's device location services.

DesktopWidget does not collect real-time GPS location or track user movements.

## Information We Do Not Collect

DesktopWidget does not collect:

- Names or personal identification information
- Email addresses
- User files or documents
- Passwords
- Browsing history
- Device hardware identifiers
- GPS location data
- Precise user location obtained from the device

## Third-Party Services

DesktopWidget may use third-party services to provide weather information and application update services.

These services receive only the information necessary to provide the requested function.

DesktopWidget does not sell or share user information for advertising purposes.

## Data Storage and Security

Anonymous statistics are transmitted through secure network connections.

DesktopWidget does not store personal information on external servers.

## Updates

DesktopWidget may periodically check for new versions.

Update checks may transmit the current application version to determine whether a newer version is available.
