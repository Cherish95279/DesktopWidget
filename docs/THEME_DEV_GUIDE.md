# DesktopWidget 主题制作开发指南

本文档面向主题设计师与开发者，说明如何从零制作一个可导入的主题压缩包。

---

## 1. 画布总规格

| 项目 | 数值 |
|------|------|
| 画布尺寸（宽×高） | **400 × 297 像素** |
| 钟表中心点坐标 | **(201, 144)** |
| 窗口固定尺寸 | 400 × 297（不可缩放） |
| 指针旋转枢轴（图内坐标） | **(199, 143)** |

> 所有 5 张图片的像素尺寸**必须**都是 **400 × 297**，与画布一致。
> 图片以左上角 (0,0) 对齐绘制到画布上，不做缩放。

---

## 2. 主题文件清单

一个主题由以下图片组成：

| 文件名 | 必需 | 说明 |
|--------|:----:|------|
| \`bg.png\` | ✅ 必需 | 背景层，最先绘制，会受不透明度/着色影响 |
| \`face.png\` | ✅ 必需 | 表盘层，绘制在背景之上、指针之下 |
| \`Hour_Hand.png\` | 可选 | 时针，缺失则回退默认主题指针 |
| \`Minute_Hand.png\` | 可选 | 分针，缺失则回退默认主题指针 |
| \`Second_Hand.png\` | 可选 | 秒针，缺失则回退默认主题指针 |

> \`bg.png\` 和 \`face.png\` **同时存在**才算有效主题，否则导入校验不通过。

---

## 3. 图层绘制顺序

从底到顶依次绘制：

1. **bg.png** — 背景层
   - 受"不透明度"滑块控制（20%–100%）
   - 受"着色强度"控制：以 \`SourceAtop\` 混合模式叠加用户选定的背景颜色
   - 建议用半透明或可着色的底色，纯白/纯黑会影响着色效果
2. **face.png** — 表盘层
   - 不受不透明度/着色影响，原样绘制
   - 适合放表盘刻度、数字、装饰边框、钟表中心装饰
3. **Hour_Hand.png** — 时针（旋转绘制）
4. **Minute_Hand.png** — 分针（旋转绘制）
5. **Second_Hand.png** — 秒针（旋转绘制）
6. **文字信息** — 8 个显示项目由程序绘制在最上层（见第 5 节）

---

## 4. 指针绘制规范（关键）

### 4.1 指针图片尺寸

每张指针图片同样是 **400 × 297 像素**，画布其余区域保持**透明**（RGBA，alpha=0）。

### 4.2 指针朝向：必须指向 12 点钟方向

在源图片的**未旋转状态（0°）**下，指针必须指向正上方（12 点钟方向）。

- 0° = 指向上（12 点）
- 顺时针旋转
- 90° = 指向右（3 点）
- 180° = 指向下（6 点）
- 270° = 指向左（9 点）

> 设计要点：在 400×297 画布中，把指针画成**从中心 (199,143) 向上延伸**的形状。

### 4.3 指针旋转中心（枢轴）

程序在绘制指针时执行以下变换：

\`\`\`
1. 平移到画布中心 (201, 144)
2. 旋转角度
3. 在 (-199, -143) 处绘制指针图片
\`\`\`

这意味着指针图片内的 **(199, 143) 像素点**会对齐到画布中心 (201, 144)。

| 坐标 | X | Y | 说明 |
|------|---|---|------|
| 画布中心 | 201 | 144 | 钟表旋转中心 |
| 指针图内枢轴 | 199 | 143 | 指针图片中应对齐中心的像素 |

> 设计要点：指针的旋转轴（尾部尖端或中心圆点）应放在图片的 **(199, 143)** 位置。
> 指针主体从该点向上延伸，长度自行设计（不要超出画布边界）。

### 4.4 旋转角度公式

| 指针 | 角度计算 | 每格步进 |
|------|----------|----------|
| 时针 | (hour % 12) × 30° + minute × 0.5° | 每小时 30°，每分钟 0.5° |
| 分针 | minute × 6° + second × 0.1° | 每分钟 6°，每秒 0.1° |
| 秒针 | second × 6° | 每秒 6° |

## 5. 八个显示项目的位置

程序在图片之上绘制 8 个文字信息槽位。每个槽位为矩形区域 (x, y, width, height)，
文字左对齐 + 垂直居中。主题设计时**应避开这些区域**，或在这些区域留出足够对比度的底色。

### 5.1 槽位坐标表

| 槽位 | X | Y | 宽 W | 高 H | 默认内容 |
|------|---|---|------|------|----------|
| slot_1 | 20 | 30 | 105 | 43 | 天气（城市/天气/温度，两行） |
| slot_2 | 20 | 86 | 85 | 43 | 网速（↓下载/↑上传，两行） |
| slot_3 | 20 | 166 | 70 | 50 | 分辨率 |
| slot_4 | 20 | 235 | 88 | 50 | 日期（日期/星期，两行） |
| slot_5 | 280 | 30 | 94 | 43 | IP 地址 |
| slot_6 | 314 | 86 | 71 | 43 | GPU 占用 |
| slot_7 | 324 | 166 | 60 | 50 | 内存（标签/百分比，两行） |
| slot_8 | 273 | 238 | 97 | 43 | 磁盘总占用（标签/百分比，两行） |

> 用户可在设置中自定义每个槽位显示的内容，但**位置区域固定不变**。
> 多行内容时，高度 H 被均分为两行，每行高 H/2。

### 5.2 槽位布局示意图

\`\`\`
(0,0)──────────── 400 ────────────┐
│                                  │
│  slot_1            slot_5        │  ← Y=30
│  (20,30,105,43)    (280,30,94,43)│
│                                  │
│  slot_2            slot_6        │  ← Y=86
│  (20,86,85,43)     (314,86,71,43)│
│                                  │
│         ◷ 钟表中心               │
│       (201,144)                  │
│                                  │
│  slot_3            slot_7        │  ← Y=166
│  (20,166,70,50)    (324,166,60,50)│
│                                  │
│  slot_4            slot_8        │  ← Y=235
│  (20,235,88,50)    (273,238,97,43)│
│                                  │
└──────────────────────────────────┘ 297
\`\`\`

### 5.3 可显示的内容类型

槽位可配置为以下任意一种内容（用户在设置中选择）：

| 内容键 | 说明 | 格式示例 |
|--------|------|----------|
| weather | 天气 | ☀️ 晴 25℃（两行：城市/天气） |
| netspeed | 网速 | ↓12.3Mb/s / ↑4.5Mb/s（两行） |
| resolution | 屏幕分辨率 | 1920×1080 |
| date | 日期 | 2026/08/31 / 周日（两行） |
| ip | IP 地址 | 192.168.1.1 |
| gpu | GPU 占用 | GPU45% |
| memory | 内存 | 内存 / 65%（两行） |
| disk_total | 磁盘总占用 | 磁盘 / 70%（两行） |
| cpu | CPU 占用 | CPU30% |
| uptime | 运行时长 | 2h15m |
| lunar | 农历 | 八月初九 |
| term | 节气 | 处暑 |
| empty | 空 | （不显示） |

## 6. 字体与颜色

文字信息由程序绘制，主题设计师无需在图片中包含文字。程序读取的字体设置：

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| font_family | Microsoft YaHei | 用户可改 |
| font_size | 10 | 用户可改 |
| font_color | #1c344d | 用户可改 |

> 主题设计建议：背景在这些文字区域使用较浅或较深的纯色底，
> 保证与可变字体颜色有足够对比度。

---

## 7. 背景着色机制（重要）

\`bg.png\` 会被程序叠加一层用户选定的背景颜色，混合模式为 \`SourceAtop\`：

- 用户可选颜色：经典暗色 #1c344d / 浅色主题 #f0f0f0 / 浅蓝灰 #a8c7dc / 自定义
- 着色强度滑块：0–255（默认 80），alpha 越高颜色越浓
- \`SourceAtop\` 模式：颜色只覆盖 bg.png 中**不透明**的像素区域

> 设计建议：
> - bg.png 的透明区域着色后仍保持透明
> - bg.png 的半透明区域会与颜色混合，可用来做渐变效果
> - face.png 不受着色影响，适合放不需要变色的固定装饰

## 8. 压缩包制作规范

### 8.1 目录结构（推荐：文件夹结构）

压缩包内包含一个以主题名命名的文件夹，文件夹内放 5 张图片：

\`\`\`
我的主题.zip
└── 我的主题/
    ├── bg.png           ← 必需，400×297
    ├── face.png         ← 必需，400×297
    ├── Hour_Hand.png    ← 可选，400×297，指针指向12点
    ├── Minute_Hand.png  ← 可选，400×297，指针指向12点
    └── Second_Hand.png  ← 可选，400×297，指针指向12点
\`\`\`

> 文件夹名即为主题在下拉框中的显示名，支持中文。

### 8.2 目录结构（兼容：扁平结构）

素材直接放在压缩包根目录，程序用 zip 文件名作为主题名：

\`\`\`
我的主题.zip
├── bg.png
├── face.png
├── Hour_Hand.png
├── Minute_Hand.png
└── Second_Hand.png
\`\`\`

### 8.3 格式要求

- 压缩格式：**ZIP**（.zip）
- 图片格式：**PNG**（支持透明通道，必须用 RGBA）
- 图片尺寸：统一 **400 × 297 像素**
- 文件名：严格区分大小写，使用上面列出的英文名

### 8.4 校验规则

导入时程序会自动校验：

| 检查项 | 结果 |
|--------|------|
| 含 bg.png + face.png | ✅ 校验通过，可导入 |
| 缺 bg.png 或 face.png | ❌ 缺少 bg.png, face.png（列出具体缺哪个） |
| 缺指针图片 | ✅ 校验通过，提示缺失的可选素材，导入后回退默认指针 |
| 完全无素材 | ❌ 压缩包缺少必需素材 |

### 8.5 命名冲突

如果导入的主题名与已有主题重名，程序自动追加 \`_2\`、\`_3\` 后缀，不会覆盖已有主题。

---

## 9. 完整制作流程清单

1. 新建 400 × 297 像素、RGBA 透明背景的画布
2. 绘制 \`bg.png\`：
   - 背景底色/纹理，会着色，透明区域保持透明
   - 避开或为 8 个文字槽位区域留出可读底色
3. 绘制 \`face.png\`：
   - 表盘刻度、数字、边框装饰、钟表中心装饰
   - 不受着色影响，原样显示
4. 绘制三张指针图片（\`Hour_Hand.png\` / \`Minute_Hand.png\` / \`Second_Hand.png\`）：
   - 400 × 297 透明画布
   - 指针指向正上方（12 点钟方向）
   - 旋转轴心放在图片 (199, 143) 像素处
   - 指针主体从轴心向上延伸
5. 导出为 PNG（保留透明通道）
6. 打包为 ZIP（文件夹结构或扁平结构均可）
7. 在设置 → 主题页面点击"导入主题"，选择 zip，校验通过后导入
