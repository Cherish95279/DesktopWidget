# ✨ 项目简介

DesktopWidget 是一款面向 Windows 的一体化桌面小组件应用，旨在让用户能够快速获取桌面信息，同时保持桌面的简洁与美观。

它集成了指针时钟、实时天气、系统性能监控、网络速度监控、农历日期、节气信息、自定义主题、公告管理以及自动更新等功能，为用户提供轻量、高效且可定制的桌面体验。

DesktopWidget 基于 **PyQt6** 开发，注重性能、自定义能力和易用性，适合日常使用，也适合喜欢折腾和个性化桌面的用户。

# 🏗️ 项目架构

DesktopWidget 基于 Python 和 PyQt6 构建，采用模块化架构设计。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| Python 3.12 | 核心开发语言 |
| PyQt6 | 图形界面框架 |
| psutil | CPU / 内存 / 网络监控 |
| GPUtil | GPU 监控 |
| requests | 网络请求 |
| zhdate | 农历日期转换 |
| Pillow | 图像处理 |
| PyInstaller | 程序打包 |
| Inno Setup | Windows 安装包制作 |

---

## 项目结构

项目采用模块化设计：

```text
DesktopWidget/
│
├── src/
│   ├── widgets/              # 核心组件
│   ├── settings_pages/       # 设置页面
│   ├── mixins/               # 功能扩展模块
│   ├── notice/               # 公告系统
│   └── i18n/                 # 国际化系统
│
├── screenshots/              # 截图与预览资源
├── icons/                    # 应用图标
├── skins/                    # 主题资源
├── installer/                # Inno Setup 语言包
│
├── widget.py                 # 程序入口
├── DesktopWidget.spec        # PyInstaller 打包配置
├── DesktopWidget.iss         # Inno Setup 安装脚本
├── LICENSE                   # MIT 开源协议
└── README.md
```

模块化结构使 DesktopWidget 更容易维护、扩展和二次开发。

# 🛠️ 开发说明

## 环境要求

- Windows 10 / Windows 11
- Python 3.12+

---

## 从源码运行

克隆仓库：

```bash
git clone https://github.com/Cherish95279/DesktopWidget.git

cd DesktopWidget
```

创建虚拟环境：

```bash
python -m venv .venv
```

安装依赖：

```bash
pip install PyQt6 psutil requests zhdate GPUtil Pillow
```

运行：

```bash
python widget.py
```

---

## 构建发布版本

DesktopWidget 使用：

- **PyInstaller** 生成可执行文件
- **Inno Setup** 制作 Windows 安装程序

官方发布安装包：

```text
DesktopWidget-windows-x64-Setup.exe
```
