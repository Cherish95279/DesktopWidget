# Security Policy

## Reporting a Security Vulnerability

If you discover a security vulnerability in DesktopWidget, please do not report it through a public GitHub Issue or Pull Request.

Instead, please use GitHub's **Private Vulnerability Reporting** feature to report the issue privately.

You can access private vulnerability reporting from the **Security and quality** tab of this repository.

If private vulnerability reporting is unavailable, please contact the project maintainer through the contact method provided in the repository.

## What to Include

Please provide as much relevant information as possible, including:

* A clear description of the vulnerability.
* The affected DesktopWidget version.
* The affected Windows version.
* Steps to reproduce the issue.
* The potential security impact.
* Relevant logs, screenshots, or proof-of-concept information, if available.

Please do not include passwords, API keys, access tokens, or other sensitive credentials in your report.

## Supported Versions

Security fixes are generally provided for the latest stable version of DesktopWidget.

Older versions may not receive security updates. Users are encouraged to update to the latest available version.

| Version               | Security Support |
| --------------------- | ---------------- |
| Latest stable release | Supported        |
| Older releases        | Not guaranteed   |

## Responsible Disclosure

Please allow reasonable time for the vulnerability to be investigated and, when appropriate, fixed before publicly disclosing the vulnerability.

We appreciate responsible security research and will make reasonable efforts to investigate reported security issues.

## Security Advisories

When appropriate, confirmed security vulnerabilities may be documented through GitHub Security Advisories.

Security advisories may include information about affected versions, fixed versions, and recommended actions for users.

## Scope

This security policy applies to the DesktopWidget source code and official software releases maintained in this repository.

Third-party services, operating systems, external APIs, and other software dependencies may have their own security policies and reporting procedures.
